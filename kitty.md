# kitty

#### Keyboard shorcuts

Kitty keyboard shortcuts generally start with Ctrl-Shift  - refer below <br>
https://sw.kovidgoyal.net/kitty/overview/

Below are custom shortcuts that I have added to ~/.config/kitty/kitty.conf <br>
 - Ctrl-Shift-n : Opens a new window in current working directory
 - Ctrl-Shift-h : Opens terminal scrollback history in default kitter pager (I
   have set as neovim)
 - Ctrl-Shift-g : Similar to above but only  shows last command.
